# Constitution

This component has no component-level constitution. It conforms to the **family-wide
constitution** owned by the governance hub:

> `document-processor-orchestration` → `docs/constitution.md` (v1.1)

Component `.opencode/` agents and commands reference the hub constitution directly.
Historical backend constitution (v1.1) and its amendment log are preserved in
`docs/constitution-amendments/` (see `001-ocr-typing-tradeoff.md`, mirrored in `docs/adr/011`).
